{{- if eq .Values.database.type "sqlite" }}

NOTE: SQLite runs exactly one engine replica, so engine upgrades and node drains cause a short
      API outage (the dashboard stays up). For zero-downtime upgrades move to PostgreSQL or MySQL:
        farrier db migrate --to "postgresql://farrier@db/farrier?sslmode=verify-full"
      then set database.type and database.url. Back up the {{ .Values.engine.persistence.size }} PVC data-{{ $engineName }}-0 daily.
{{- else if and (gt $replicas 1) (not .Values.engine.storage.url) }}

NOTE: engine.storage.url is empty, so each of the {{ $replicas }} engine replicas keeps change packs and
      other files in its own emptyDir, lost on restart. Set engine.storage.url (s3://, gs://,
      azblob://) so every replica shares them.
{{- end }}
